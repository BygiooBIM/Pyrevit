# BygiooBIM pyRevit

Extensión pyRevit para Revit 2026. La raíz del repo es la extensión (`BygiooBIM.tab/`, `lib/`).
Antes de escribir o corregir cualquier herramienta, usa la skill `pyrevit-revit`
(`.claude/skills/pyrevit-revit/SKILL.md`). El usuario prueba en Revit (Windows); aquí no se puede ejecutar Revit.
Responde en español.
